Design contains the core principles of the PrintNC project and preview/release CAD files for the Metalcutter, Woodcutter, Desktop and Mini versions of the PrintNC V4, as well as user created mods.

Metalcutter (for primarily aluminum and high-speeed milling of mild steel) and Woodcutter (for primarily wood sheetstock and hardwood slabs) 
CAD files are found in the V4_MC-WC_CAD folder. Presets are the same CAD file with different parameters and parts hidden/displayed. 

Build of Materials script is available here: https://github.com/interias/PrintNC-BOM-Generator
